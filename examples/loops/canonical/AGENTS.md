# Shipping quote fixture

Implement only the selected sprint in `cmd/quote/main.go`, and commit that
source change. Demonstrate the public CLI with `go run ./cmd/quote`.
Future sprint work stays for its own lap.

The Go tests and sprint documents are the acceptance contract; do not edit
them. The Gimble engine owns ledger `done` fields. Evidence JSON is generated
output. This module uses only the Go standard library.
