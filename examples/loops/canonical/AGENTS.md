# Shipping quote fixture

This is a disposable application workspace. Implement only the currently
selected sprint in `quote.py`, and commit that source change. Use the public
CLI to demonstrate it. Future sprint work stays for its own lap.

`check.py` and the sprint documents are the acceptance contract; do not edit
them. The Tractor engine owns all ledger `done` fields. Evidence JSON files
are generated output and need not be committed. No packages are required.
