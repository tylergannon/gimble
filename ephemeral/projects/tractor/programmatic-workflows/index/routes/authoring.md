# Ordinary code, graphs, and nested loops

- For the closest imperative coding-agent workflow, stages, loops, and typed replies: [Orca](../leaves/imperative-orca.md). Read the actual README loop before the optional checkpoint ADR.
- For ordinary Go callbacks and named runtime steps without declared edges: [Genkit Go](../leaves/imperative-genkit-go.md). Generic flow outputs are not automatically an LLM wire contract.
- For typed code that still deliberately materializes a graph: [Pydantic Graph](../leaves/imperative-pydantic-graph.md). Its diagram guarantee comes from known nodes and edges.
- For configured sequential/loop agent composition and agent-tree rendering: [ADK Go](../leaves/imperative-adk-go.md). Distinguish composition from arbitrary Go policy.
- For Go dependency-query builders versus normal functional task code: [Dagger and LangGraph](../leaves/static-alternatives.md).
- For today's nested YAML, loop-body ownership and existing public runtime: [Tractor](../leaves/static-tractor.md).
- For deterministic or checkpointed code rather than a new authoring DSL: [Temporal](../leaves/durable-temporal-go.md), [Restate](../leaves/durable-restate-go.md), [DBOS](../leaves/durable-dbos-go.md).
