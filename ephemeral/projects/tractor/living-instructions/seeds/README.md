# Seeds

Product descriptions the validation scenarios feed to `plan`. Each is
written before the chapter that consumes it starts and is not edited
afterwards; `validation/P10/design.md` records the commit that fixed the
two P10 seeds, and its proof script fails if they differ from that
commit. The scenario seeds for P1, P2, P4, and P7 are written by chapter
5 when their sprints start and follow the same rule.
