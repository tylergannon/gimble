# Optional timeout for `tractor ask`

Should `tractor ask` accept `--timeout`, and if so what should it print when
the timeout expires?

- Omit a timeout. The command blocks until an answer, or until its process is
  interrupted; rerunning with the numbered question resumes the wait.
- Add `--timeout <duration>`. On expiry, return nonzero with an error naming
  the still-waiting numbered question path.

Recommendation: omit it for this sprint. Blocking is the command's contract,
process cancellation already bounds callers that need it, and the documented
resume path handles a cut-off shell without adding another lifecycle state.
