# Brief lap 1: findings from research

Five questions, batched (decision 39). Each changes a promise, its scope,
or its verifier; each has a recommendation. Evidence is in
`research/findings.md`.

1. **Restate P8's `show` clause.** "`show` prints each node's prompt
   exactly as `Build` materialized it for the given parameters", plus an
   optional `--stage <dir>` that diffs against a real stage with the
   frame stripped. Byte-equality against the engine's `prompt.md` is
   impossible because frames and `$goal` are added at run time.
   Recommend: yes.

2. **Restate P8's Go-string clause.** "Every prompt body, doctrine page,
   supervisor brief, pass, and skeleton is a library file; Go supplies
   only data values to templates." Otherwise the first computed path
   string violates it. Recommend: yes.

3. **Add a seventh review pass, holistic and rubric-free.** "Would you
   accept this as the plan for this product, and what one thing would
   stop you." Evidence: single-criterion judges credit mere mention and
   miss trade-offs between criteria; rubric-free judges did not prefer
   rubric-hacked output. Recommend: yes, last in order.

4. **Cheap-role model.** `claude-sonnet-5` is not a name any backend here
   accepts. Options: the `sonnet` alias on the claude backend; a gemini
   flash name through agy with an explicit provider. Recommend: `sonnet`
   on claude, provider always explicit.

5. **Template delimiters.** `{{` in doctrine text collides with
   `text/template`. Recommend: non-default delimiters, decided before any
   page is written; exact pair is the coder's call.
