# Empty answer input behavior

When `tractor answer <question-path>` receives neither a text argument nor
piped stdin, should it open `$EDITOR` or fail?

- Open `$EDITOR`, adding an interactive fallback.
- Fail with an error that asks for a text argument or stdin.

Recommendation: fail. It keeps the command deterministic for agents and
automation, avoids hanging when no editor or terminal is available, and does
not prevent adding an explicit editor mode later.
