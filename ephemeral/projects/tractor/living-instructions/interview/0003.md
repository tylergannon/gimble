# Run directory in the agent preamble

Should `TRACTOR_RUN_DIR` also be written into the `<system-message>` preamble,
with `tractor ask --run <dir>` as an explicit fallback for backends that scrub
the process environment?

- Yes: add the preamble field and `--run` flag now, providing a second route to
  the run timeline.
- No: keep the run directory environment-only for this sprint; every supported
  backend is required and tested to inherit it.

Recommendation: no. The sprint contract already requires all supported
backends to preserve `TRACTOR_RUN_DIR`, and adding a prompt field plus a second
CLI input path would broaden the interface without current evidence that a
supported backend scrubs the environment. We can add the fallback if a backend
actually requires it.
