The random path and nonce do not hide the fixed `observer:` signature. Owning node: design. Promises: P1–P7, P9, P10.

P5, P6, and P10 explicitly leave their decisive run records forgeable by in-scope workflow code while appealing to an uncaptured “diff review.” `validation/P5/design.md` says: “That no agent or tool node forged run-directory records … would be a defect of the diff review of the graph and prompts, not of this check.” `validation/P6/design.md` likewise admits that “every tool command receives the run directory's path and could write stage files or append events.” `validation/P10/design.md` repeats the same concession. No listed evidence or inference captures the asserted diff review, so a tool node can fabricate the exact records while the promises are false. Owning node: design. Promises: P5, P6, P10.
