# Source leaf: `docs/five-arts.md`

## Purpose

The project-level aims and tensions that the Go-program direction must serve:
evidence, decomposition, authoring, visibility, and steering.

## Key concepts

- The five arts are competing priorities, not a checklist:
  `docs/five-arts.md:1-10`.
- Ensure agents do the work with evidence rather than assertion:
  `docs/five-arts.md:12-16`.
- Split work so no agent carries more than it can get right:
  `docs/five-arts.md:17-20`.
- Help humans define and author the work, and help both audiences see progress:
  `docs/five-arts.md:21-30`.
- Let observers steer work in flight: `docs/five-arts.md:31-34`.
- Key tensions include evidence versus steering, decomposition versus
  visibility, authoring versus independent checking, and decomposition versus
  enough context to judge the whole: `docs/five-arts.md:36-49`.

- Use `docs/five-arts.md:36-49` when evaluating a tradeoff in agent splits,
  diagrams, or supervision.
