# skgo editor port

- skgo main moved (c64663c -> 7c86073, in-process SSR with goja) while this
  was in flight. Copying `skgo-adapter.js` from the live checkout broke the
  build against the pinned module ("Could not resolve 'esbuild'"). Always
  copy the adapter from the pinned version in the Go module cache.
- Stayed on c64663c: the editor is CSR and 7c86073 adds goja to every
  importer's binary. Bumping is a deliberate step described in
  ephemeral/projects/tractor/skgo-editor/report.md.
- skgo resolved as a private module with GOPRIVATE and a pseudo-version; no
  `replace`. Until the repo is public, `go generate ./internal/editor/...`
  and a fresh `go mod download` need GOPRIVATE=github.com/tylergannon/skgo.
- `#lib` subpath imports resolve without extension probing under kit 3:
  `svelte-check` needs `#lib/model.ts`, `vp build` does not. A page can ship
  with a red type check; CI runs the check.
- Raising the `go` directive to 1.27.1 made `go tool modernize` rewrite
  unrelated tests and graph/parse.go in the pre-commit hook. Those hunks are
  in the first commit of this branch, not a separate change.
- The Chrome extension was not connected; Playwright from the scratchpad,
  against the cached Chromium, gave the browser proof instead. The driver is
  kept at ephemeral/projects/tractor/skgo-editor/proof/drive.mjs.
